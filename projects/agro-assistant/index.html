El reto

Los productores necesitan respuestas rápidas sobre cultivos, plagas y enfermedades, pero la información confiable suele estar repartida en documentos técnicos difíciles de consultar en campo.

La solución

Construí un asistente con arquitectura RAG sobre Gemini File Search que responde a partir de la documentación cargada, y un módulo que analiza imágenes del cultivo para sugerir un diagnóstico.

Lo más destacado

  • RAG con Gemini File Search sobre documentación técnica agrícola.
  • Diagnóstico de plagas y enfermedades a partir de imágenes.
  • API con NestJS y frontend con Nuxt.

Resultado

El productor pregunta en lenguaje natural y recibe respuestas respaldadas por las fuentes, además de un diagnóstico inicial a partir de una foto.
